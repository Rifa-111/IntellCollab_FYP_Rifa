# Contributing

Contributions are welcome if they improve clarity, tests, reproducibility or safe research practice. File an issue describing the problem and a minimal reproducible example, then submit a pull request.

Before submitting, run:

```bash
python -m unittest discover -s tests -v
python -m intellcollab
```

Use only synthetic or appropriately licensed data in examples. Do not include API keys, database URLs, personal data, hard-coded passwords or unsupported outcome claims. Add regression coverage for ranking changes and explain any changes to scoring semantics.

No top-level open-source licence has yet been selected. Public visibility does not itself authorise redistribution. The repository owner should select a licence before inviting broad reuse.
